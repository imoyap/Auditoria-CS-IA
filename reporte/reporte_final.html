Hallazgos

H-01 — Bindshell root sin autenticacion expuesto en 1524/tcp (Metasploitable root shell) VALIDADO

SRV-ADM-01 es el servidor de administracion interna de Comercial Andes Sur, alcanzable desde la misma red corporativa plana donde trabajan las 140 personas de la dotacion. Un shell root sin autenticacion en 1524/tcp entrega control total del host a cualquiera que alcance esa red, incluyendo ruta lateral hacia los sistemas que tratan datos de clientes (nombre, RUT, direccion, telefono, historial de compra) y datos sensibles de trabajadores (licencias medicas), lo que activa el deber de seguridad de la Ley 21.719 sobre ese tratamiento.

BrechaNo existe proceso de hardening ni revision periodica de servicios expuestos en SRV-ADM-01; el host no tiene un procedimiento de baja de servicios no autorizados ni de verificacion de integridad de binarios frente a compromisos de cadena de suministro.
Remediación / RecomendaciónBloquear de inmediato 1524/tcp en el firewall de host como contencion; identificar y eliminar el binario/servicio que abre el shell root (compatible con un troyano de cadena de suministro, no una version de software regular); verificar integridad de todo el sistema contra una imagen conocida-buena y, si se confirma compromiso, reconstruir el host antes de reconectarlo a la red de administracion.

H-02 — vsftpd 2.3.4 con backdoor conocido embebido en el binario, puerto 21/tcp OBSERVADO

SRV-ADM-01 corre vsftpd 2.3.4 (version con backdoor documentado, CVE-2011-2523) en la misma red plana de administracion de Comercial Andes Sur; de activarse el backdoor, el atacante obtiene un shell que alcanza los sistemas que procesan datos personales de clientes y datos sensibles de trabajadores, exactamente el tipo de riesgo que la Ley 21.663 exige gestionar en un activo de administracion como este.

H-03 — UnrealIRCd con troyano/backdoor conocido, puertos 6667 y 6697 tcp INCONCLUSO

El hallazgo original atribuye a SRV-ADM-01 un troyano conocido de UnrealIRCd 3.2.8.1 (CVE-2010-2075), pero evidencias/raw/01_nmap_full.txt no contiene el numero de version del servicio IRC en 6667/6697 tcp, solo mensajes NOTICE AUTH genericos de conexion. No se puede afirmar que el activo de Comercial Andes Sur corra la version troyanizada, por lo que tampoco corresponde aseverar que se activa una obligacion normativa especifica sobre un riesgo aun no confirmado (mismo criterio del Ejemplo 3 del Anexo Tecnico U3: sin verificacion no se fuerza una calificacion).

H-04 — distccd sin autenticacion permite ejecucion remota de comandos, puerto 3632/tcp OBSERVADO

distccd v1 esta expuesto en 3632/tcp de SRV-ADM-01 sin ninguna lista de control de acceso, permitiendo ejecucion remota de comandos arbitrarios (CVE-2004-2687) a cualquiera que alcance la red plana de administracion de Comercial Andes Sur; dado que este host es el servidor de administracion interna, su compromiso habilita pivoteo hacia los sistemas que tratan datos personales de clientes y datos sensibles de trabajadores, el tipo de riesgo que la Ley 21.663 exige gestionar y, de materializarse, reportar.
